# KubeRich Homebrew tap

The project-owned Homebrew distribution repository for [KubeRich](https://github.com/carloshm91/kuberich), a Kubernetes terminal workspace built with Python and Textual.

The first formula is being prepared. After its reviewed activation, install it with:

```sh
brew install kuberich/tap/kuberich
```

Update and remove it with:

```sh
brew update
brew upgrade kuberich/tap/kuberich
brew uninstall kuberich/tap/kuberich
```

Formulas use immutable published sources and verified SHA-256 checksums. Formula changes run style, online audit, source installation, CLI tests and uninstall checks on Linux and macOS before merging. Commits require a Developer Certificate of Origin sign-off.
